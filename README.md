# Sistema de Álgebra Linear
Este projeto foi desenvolvido como parte dos estudos de Álgebra Linear, utilizando Python para trabalhar com matrizes e operações matemáticas. O projeto começou com uma aplicação executada pelo terminal e depois recebeu uma interface gráfica utilizando a biblioteca Tkinter. A ideia principal é permitir a criação de matrizes, visualizar seus valores e realizar operações comuns de Álgebra Linear de uma maneira simples e visual.
## Estrutura do projeto
O projeto foi organizado separando as responsabilidades de cada arquivo. O arquivo main.py contém o programa principal executado pelo terminal. O arquivo entrada.py é responsável pela entrada dos dados das matrizes. O arquivo apresentacao.py possui funções utilizadas para mostrar as matrizes de maneira organizada. O arquivo validacoes.py concentra as validações utilizadas durante a entrada dos dados. O arquivo calculos.py concentra as operações matemáticas realizadas nas matrizes. A pasta interface contém a calculadora gráfica criada com Tkinter. Essa separação permite que a interface gráfica utilize as mesmas funções matemáticas do programa principal sem precisar alterar o funcionamento do núcleo do projeto.
## NumPy
Uma das principais bibliotecas utilizadas no projeto é a NumPy. NumPy significa Numerical Python e é uma biblioteca muito utilizada em Python para trabalhar com cálculos numéricos, principalmente com arrays e matrizes. Em Álgebra Linear, ela é muito importante porque possui estruturas e funções próprias para realizar operações matemáticas de forma eficiente. Neste projeto, o NumPy é utilizado principalmente no arquivo calculos.py. Quando uma matriz criada pelo programa é enviada para uma operação, ela pode ser transformada em um array do NumPy utilizando np.array(). Isso permite utilizar as funções matemáticas disponíveis na biblioteca.
## Determinante
O NumPy é utilizado para calcular o determinante de uma matriz através da função np.linalg.det(). O módulo linalg significa Linear Algebra e possui diversas funções relacionadas à Álgebra Linear. No projeto, a função determinante recebe uma matriz, transforma essa matriz em um array do NumPy e utiliza np.linalg.det() para calcular seu determinante. Por exemplo, uma matriz [[1, 2], [3, 4]] possui determinante igual a -2. O resultado é utilizado tanto pelo programa do terminal quanto pela calculadora gráfica.
## Inversa
Outra operação realizada pelo NumPy é o cálculo da matriz inversa. Para isso, o projeto utiliza np.linalg.inv(). Antes de calcular a inversa, o programa verifica se a matriz é quadrada e se possui inversa. Uma matriz que possui determinante igual a zero não possui inversa. Quando a matriz possui inversa, o NumPy realiza o cálculo através de np.linalg.inv(). Para uma matriz [[1, 2], [3, 4]], por exemplo, a inversa é [[-2, 1], [1.5, -0.5]].
## Verificação da inversa
O projeto também possui uma operação para verificar se uma matriz possui inversa. Essa verificação utiliza o determinante. Se o determinante for diferente de zero, a matriz possui inversa. Se o determinante for igual a zero, a matriz não possui inversa. Essa função utiliza np.linalg.det() através da função determinante criada no projeto.
## Matriz transposta
A transposta também é calculada utilizando NumPy. No código, a operação é feita através de .T. A transposta troca as linhas pelas colunas. Por exemplo, se A = [[1, 2], [3, 4]], sua transposta será [[1, 3], [2, 4]]. O NumPy permite realizar essa operação de maneira simples utilizando np.array(matriz).T.
## Multiplicação de matrizes
A multiplicação de matrizes é outra operação disponível no sistema. O projeto utiliza o operador @ do Python junto com os arrays do NumPy. O operador @ representa a multiplicação matricial. Para que duas matrizes possam ser multiplicadas, o número de colunas da primeira matriz precisa ser igual ao número de linhas da segunda matriz. No programa, essa condição também é verificada antes da operação. O resultado é calculado utilizando np.array(A) @ np.array(B).
## Por que utilizar NumPy
O NumPy foi utilizado porque é uma biblioteca muito importante para computação numérica em Python e possui recursos específicos para trabalhar com Álgebra Linear. Sem o NumPy, seria necessário implementar manualmente várias operações matemáticas, como cálculo de determinante, inversa e multiplicação matricial. Neste projeto, o objetivo é justamente aprender a utilizar Python e uma biblioteca bastante utilizada na área de Inteligência Artificial e Ciência de Dados. Por isso, o NumPy faz parte do núcleo matemático do sistema.
## Tkinter
A interface gráfica do projeto foi desenvolvida utilizando a biblioteca Tkinter. Tkinter é uma biblioteca que permite criar interfaces gráficas em Python. Com ela é possível criar janelas, botões, campos para digitação, textos, caixas de organização e outros elementos visuais. Uma das vantagens do Tkinter é que ele já faz parte da instalação padrão do Python em muitas instalações, não sendo necessário instalar uma biblioteca externa separada para começar a criar uma interface gráfica.
## Como o Tkinter funciona
O funcionamento do Tkinter é baseado em uma janela principal e em componentes chamados widgets. A janela principal é criada através de tk.Tk(). Dentro dessa janela são colocados os elementos da interface, como Label, Entry, Button, Frame e LabelFrame. Cada componente possui uma função específica. O Label é utilizado para apresentar textos. O Entry é utilizado para receber informações digitadas pelo usuário. O Button cria botões que executam funções quando são clicados. O Frame serve para organizar outros componentes dentro da janela. O LabelFrame também organiza componentes, mas possui uma borda e um título, sendo utilizado no projeto para separar visualmente a Matriz A, a Matriz B, as operações e os resultados.
## Janela principal
No projeto, a janela é criada com tk.Tk(). Depois são definidos o título, o tamanho inicial e o tamanho mínimo da janela. Isso cria a janela principal da calculadora. O comando janela.mainloop() fica no final do programa e mantém a interface funcionando. O mainloop é importante porque cria o ciclo de funcionamento da interface. Enquanto esse ciclo está ativo, o programa fica esperando ações do usuário, como clicar em um botão ou preencher um campo.
## Campos das matrizes
Uma das partes mais interessantes da interface é que os campos das matrizes são criados de forma dinâmica. O usuário informa a quantidade de linhas e colunas e depois clica no botão para criar a matriz. A função criar_campos_matriz utiliza loops para criar os campos Entry necessários. Dessa forma, o programa não precisa saber antecipadamente se o usuário vai trabalhar com uma matriz 2x2, 3x3, 4x5 ou outra dimensão.
## Botões
Cada botão da interface possui uma função associada ao parâmetro command. Quando o usuário clica no botão, o Tkinter executa a função indicada. Por exemplo, o botão DETERMINANTE chama a função calcular_determinante(). O botão INVERSA chama calcular_inversa(). O botão TRANSPOSTA chama calcular_transposta(). O botão A × B chama calcular_multiplicacao(). Dessa forma, a interface gráfica funciona como uma camada de interação com o usuário, enquanto os cálculos continuam sendo realizados pelo arquivo calculos.py.
## Separação entre interface e cálculos
Uma decisão importante do projeto foi manter a interface gráfica separada do código responsável pelos cálculos. A calculadora está dentro da pasta interface, enquanto calculos.py continua no diretório principal. A interface importa o módulo calculos e utiliza suas funções. Isso significa que a interface não precisa refazer os cálculos e também não precisa alterar o código que já estava funcionando no terminal. Essa separação facilita a manutenção e permite que o mesmo núcleo matemático seja utilizado por diferentes formas de interação.
## Operações disponíveis
A calculadora possui criação de matriz A, criação de matriz B, visualização da matriz A, cálculo do determinante, verificação da existência de inversa, cálculo da matriz inversa, cálculo da matriz transposta e multiplicação entre matrizes A e B. A interface também verifica algumas condições antes de realizar as operações, como a necessidade de uma matriz quadrada para determinante e inversa e a compatibilidade entre as dimensões das matrizes para a multiplicação.
## Validação dos dados
A interface também possui validações para evitar erros durante a utilização. O usuário precisa informar números inteiros maiores que zero para definir as dimensões das matrizes. Os campos dos valores precisam ser preenchidos e devem conter números. O programa também aceita vírgula ou ponto como separador decimal. Por exemplo, o usuário pode digitar 1,5 ou 1.5.
## Resultado
Os resultados são apresentados dentro da própria janela gráfica. A função mostrar_resultado limpa o resultado anterior e apresenta o novo resultado. As matrizes são formatadas para facilitar a leitura. Números inteiros são apresentados sem casas decimais desnecessárias e números decimais são apresentados com uma quantidade controlada de casas.
## Tecnologias utilizadas
O projeto foi desenvolvido em Python. A biblioteca NumPy foi utilizada para as operações de Álgebra Linear, incluindo determinante, inversa, transposta e multiplicação de matrizes. A biblioteca Tkinter foi utilizada para criar a interface gráfica da calculadora. O Git e o GitHub foram utilizados para controle de versão e armazenamento do projeto.
## Objetivo do projeto
O objetivo deste projeto é praticar os conceitos de Álgebra Linear utilizando programação. A proposta também é entender como uma aplicação pode ser organizada em partes diferentes, separando entrada de dados, validações, cálculos, apresentação e interface gráfica. O projeto mostra na prática como Python pode ser utilizado para transformar conceitos matemáticos em uma aplicação funcional.
## Conclusão
O projeto começou como uma aplicação simples executada pelo terminal e evoluiu para uma calculadora gráfica de matrizes. A utilização do NumPy facilitou a implementação das operações matemáticas de Álgebra Linear, enquanto o Tkinter permitiu criar uma interface gráfica para que o usuário possa informar as matrizes e executar as operações através de botões. A separação entre o núcleo dos cálculos e a interface também permite continuar evoluindo o projeto sem precisar modificar a estrutura principal que já está funcionando.
